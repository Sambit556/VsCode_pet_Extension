# Changelog

All notable changes to the "VS Code Pet" extension will be documented in this file.

## [1.0.0] - 2026-09-10

### Initial Release
- 🐾 Virtual pet companions in VS Code Explorer (Cat, Dog, Rabbit, Hamster, Fox, Penguin).
- ⚽ Interactive physics-based Throw Ball feature.
- 🍖 Pet actions: Feed, Pet, Play, Sleep, Wake, Rename, Remove.
- 🏆 Leveling, Experience (XP), Mood, Hunger, and Energy progression systems.
- 🎨 8 Playground themes (Auto, Minimal, Dark, Cyberpunk, Forest, Space, Ocean, Retro).
- 🎩 7 Customizable pet accessories (Hat, Glasses, Bow, Headphones, Sunglasses, Backpack, Crown).
- 💻 Developer-aware build/test celebration reactions and active typing reactions.
- ⚡ Node.js & Express local backend API with randomized token authentication.
- 🔒 Enterprise security with strict CSP, isolated webview, and zero-telemetry default.
- ♿ Accessibility support (`vscodePet.reduceMotion` and muted sound by default).
